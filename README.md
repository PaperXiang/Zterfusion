# zterfusion

纯前端的本地多人同屏节奏对战游戏，像素风 UI。2–6 名玩家共用一台键盘（含鼠标按键），一人进攻打节奏、其余人复刻防守，按准确度计分。

零依赖、零构建：HTML + CSS + 原生 JavaScript，Web Audio API 发声，Canvas 2D 渲染节奏轨道，`localStorage` 保存设置。

## 运行

必须通过 HTTP 服务访问（音效库列表依赖目录索引），直接双击 `index.html` 无法加载音效库。

- Windows：双击 `启动游戏.bat`
- 或手动在项目根目录执行：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 玩法

- **配置界面**：选择模式、添加玩家（各自绑定按键、选音效）、设置 BPM / 每回合拍数 / 局数 / 回合时长 / 吸附网格（8/12/16/24 分音）。
- **进攻小节**（偶数小节）：进攻方按键打出节奏，音符自动吸附到勾选的分音网格。
- **防守小节**（奇数小节）：其余玩家复刻刚才的节奏。
- 防守小节结束后统一比对，每个进攻音与最近的防守音按误差计分。

### 模式

| 模式 | 说明 |
|---|---|
| CASUAL | 轮换进攻，攻守双方同时加分 |
| CHALLENGE A | 系统作为虚拟 P0 随机生成节奏，所有玩家防守复刻计分 |
| CHALLENGE B | 合作冲分：进攻小节音数有下限且不能与自己的上一段重复，违规记 MISS，满 3 次立即结束；团队总分越高 BPM 越快，最高分存本地 |
| CHALLENGE C | 预留，未实现 |

### 操作

- 配置界面双击 `Enter` / `Space`：快速开始
- READY 阶段按数字键：临时改拍数
- `ESC`：暂停 / 恢复

## 代码结构

| 文件 | 职责 |
|---|---|
| `config.js` | 游戏数值配置（判定窗口、软封顶等），调平衡改这里 |
| `audio.js` | Web Audio：节拍器、攻守音效、立体声声像 |
| `input.js` | 键盘/鼠标捕获、按键绑定与冲突检测 |
| `game.js` | 游戏核心：状态机、回合推进、计分、渲染、持久化 |
| `audios/` | 官方音效库（也可上传自定义音效，仅存内存） |

设置持久化在 `localStorage` 键 `rhythm-party-settings`。

## 自定义音效

玩家可为每人选择音效库音效（选择会持久化）或上传本地音频文件（仅存内存，刷新需重传）。把 `.wav` 放进 `audios/` 目录即可进入音效库下拉框。
